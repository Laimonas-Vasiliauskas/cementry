Akmens Namas

A modern and responsive business website for Akmens Namas, presenting monument manufacturing, granite work, grave restoration, cemetery maintenance, funeral services, and custom granite countertops in Klaipėda and the surrounding region.

Live Website

https://www.akmensnamas.lt

About the Project

The website was created to provide customers with clear information about the company’s services, showcase completed work, and make it easy to contact the business by phone, Viber, or WhatsApp.

The design uses a dark visual style with gold accents to create a professional and respectful appearance suitable for monument, cemetery, and funeral-related services.

Getting Started

Prerequisites

Make sure Node.js and Angular CLI are installed.

node --version
npm --version
ng version

Installation

Clone the repository and install the dependencies:

git clone <repository-url>
cd <project-folder>
npm install

Development Server

Run the project locally:

ng serve

Open:

http://localhost:4200

The application automatically reloads when source files are changed.

Production Build

Create an optimized production build:

ng build

The generated files will be stored in:

dist/

Deployment

The project is deployed with Vercel.

Every push to the connected GitHub repository automatically starts a new deployment.

git add .
git commit -m "Update website"
git push
